Visitors post comments through the public comment form. Settings decide whether comments are open, whether they
need approval, and which content is closed for comments.

## Moderation

**Comments** has tabs for pending, approved, spam and trash, each with a count.

- Approve, mark as spam, move to trash or delete one comment, or many at once.
- **Reply**: a staff reply is published immediately and the commenter gets an email.
- A new comment can notify an address you set in Settings.

## Spam protection

The public form has a hidden honeypot field and a rate limit per visitor. Visitor IP addresses are stored only as a
hash.
