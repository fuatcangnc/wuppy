## Shortcuts

| Keys | Action |
| --- | --- |
| Ctrl/⌘+S | save (also while typing) |
| Ctrl/⌘+K | search layers and commands |
| Ctrl/⌘+Z; Ctrl/⌘+Shift+Z or Ctrl/⌘+Y | undo; redo (100 steps, typing in a field is one step) |
| Ctrl/⌘+C / X / V | copy, cut, paste (after the selected block) |
| Ctrl/⌘+D | duplicate |
| Delete, Backspace | delete the selected block |
| Alt+↑ / Alt+↓ | move the selected block up or down |
| A | open Add |
| Ctrl+Alt+A | AI Select mode |
| Ctrl/⌘+0; Ctrl/⌘++ / −; Shift+1 | zoom 100%; zoom in/out; fit |
| Enter; Ctrl/⌘+Enter; Escape | commit inline text (single-line; multi-line); cancel |
| Escape | close a menu, leave the styled selector, then select the parent and clear the selection |

The list is also in the editor's **Settings**.

## Search (Ctrl/⌘+K)

Jump to any layer by name, or run a command: Add, Undo, Redo, Paste, Live or Design mode, fit the canvas, open
Framework, Selectors or Explorer, Settings.
