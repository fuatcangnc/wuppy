**Explorer** on the left rail has four tabs.

## Layers

The page tree, with search, an add button, coloured HTML tag badges, module icons and expand arrows.

- Drag rows to move them (top edge: before, bottom edge: after, middle of a container: inside); a collapsed container
  opens while you hover over it.
- Double-click a row to rename it.
- Right-click: Hide, Rename, Duplicate, Componentize, Save as layout, Copy, Cut, Paste, Wrap, Select parent,
  **Insert module here**, Lock and Delete.
- On a theme page Layers also lists the theme's own elements; see [Theme elements](/visual-editor/theme-elements/).

## Site

The Pages collection's pages, **Templates** (saved layouts) and **Components**, with counts and empty states. Click a
page to open it; drag a template onto the canvas or press its add button. **Update pages** writes a component's current
markup to every page that uses it.

## Code

A quick editor for the site stylesheet and the open page's MDX/Markdown source. For theme files and a full workspace,
use [Code view](/visual-editor/code-view/).

## Media

Search, All/Images/Videos filters, list/grid view, thumbnails and upload. Drag a file onto the canvas, or click it to
use it in the selected Image or Video block.
