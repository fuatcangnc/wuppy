Visual editor adapted from Instatic (MIT): **Edit with Visual** opens an entry on a live MDX canvas with Add, Layers, Framework, Selectors and Properties panels. Add containers, columns, headings, text, buttons, links, images, video, lists, dividers, components and Markdown blocks; drag to move, double-click to edit in place, hide/lock, style with responsive/state overrides, switch breakpoints and design/live modes, undo/redo, copy/paste, import HTML, componentize, save layouts and components. Blocks serialize to one-line `data-ve` HTML in the MDX or Markdown body, while hand-written Markdown stays untouched; saving uses the normal content API, lock, ETag and Git history. Site-wide framework/selectors/components live in `.wuppy/data/visual.json` and are served through `/api/public/visual.css`.
