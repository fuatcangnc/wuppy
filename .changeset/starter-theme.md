New sites start with a designed starter theme built on Tailwind CSS 4 and bejamas/ui. It includes a dark top bar, a sticky header with a bejamas navigation menu and drop-downs, a hero, numbered post cards, a call-to-action band and a dark footer, set in Space Grotesk with an orange accent. Brand tokens live in `src/styles/theme.css`, and more bejamas components can be added with `npx bejamas add`.
