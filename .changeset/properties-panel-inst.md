Visual editor Properties: the right-hand inspector now follows Instatic's layout with **Styles / Attributes** tabs, a selector picker and Componentize button, icon section cards, a right-edge style-category icon rail with click-to-scroll and set-value dots, a pinned style search, and dedicated Text/Tag controls. Layout, Position, Size, Spacing, Typography and Border use Instatic's icon controls for page blocks and theme elements: a Flex/Grid type switch, direction/distribute/align/wrap/gap, a T/R/B/L offset box, four-side padding/margin pickers, a four-corner radius picker, icon-labelled size fields and Align/Decor/Capitalize icon rows. Linked sides save as one undo step for blocks and one `.astro` write for themes; radius corners edit the existing shorthand. The same inspector now applies when a theme element is selected, including class pills, section actions, theme-specific breakpoint/state context and the style rail/search. Text blocks can switch between paragraph/span/div/label tags. The editor toolbar no longer overlaps the Properties panel at narrower widths, and the starter no longer ships duplicate `about.md`/`about.mdx` entries.
