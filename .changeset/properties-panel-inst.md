Visual editor Properties: the right-hand inspector now follows Instatic's layout with **Styles / Attributes** tabs, a selector picker and Componentize button, icon section cards, a right-edge style-category icon rail with click-to-scroll and set-value dots, a pinned style search, and dedicated Text/Tag, Flex/Grid, Align/Justify self, Position and Overflow controls. The same inspector now applies when a theme element is selected, including class pills, section actions, theme-specific breakpoint/state context and the style rail/search. Text blocks can switch between paragraph/span/div/label tags. The editor toolbar no longer overlaps the Properties panel at narrower widths, and the starter no longer ships duplicate `about.md`/`about.mdx` entries.
