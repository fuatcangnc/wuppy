# Changelog

Per-package changelogs are generated from `.changeset/*.md` (`pnpm changeset version`). This file lists what
shipped in the first public preview.

## 0.1.0 (unreleased)

- File-based content (Markdown/MDX) where every write is a Git commit; revisions are Git history.
- Admin: editor with autosave recovery, conflict detection and edit locks; media library; menus, widgets,
  sections, taxonomies, bylines, content types; comments; redirects; users and invitations; backups; search.
- Auth: Better Auth with passkeys, 2FA, magic links and OAuth; role/permission model.
- Plugins: QuickJS-WASM sandbox with capability approval and a signed registry.
