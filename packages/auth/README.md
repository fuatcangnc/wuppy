# @wuppycms/auth

Authentication for [WuppyCMS](https://wuppycms.com), built on [Better Auth](https://www.better-auth.com): email and
password, passkeys, two-factor sign-in and sessions, stored in SQLite.

> This package is part of [WuppyCMS](https://wuppycms.com) and is installed with `wuppycms`. You do not need to install
> it yourself.
