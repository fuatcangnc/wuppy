# @wuppycms/git

Git storage for [WuppyCMS](https://wuppycms.com). Every content save becomes a commit; the admin's history, compare and
restore read from it.

> This package is part of [WuppyCMS](https://wuppycms.com) and is installed with `wuppycms`. You do not need to install
> it yourself.
