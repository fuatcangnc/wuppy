# @wuppycms/visual-editor

The data model and CSS of the [WuppyCMS](https://wuppycms.com) visual editor, shared by the admin canvas and the site so
both render the same thing. Every style, selector and query is checked before it is written.

> This package is part of [WuppyCMS](https://wuppycms.com) and is installed with `wuppycms`. You do not need to install
> it yourself.

See [Visual editor](https://docs.wuppycms.com/visual-editor/) in the documentation.
