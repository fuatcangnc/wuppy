# create-wuppycms

Creates a new [Astro](https://astro.build) site with [WuppyCMS](https://wuppycms.com): the starter theme (Tailwind CSS 4),
sample content and the admin panel.

```sh
npm create wuppycms my-site
cd my-site
npm install
npm run dev
```

Open `http://localhost:4321/admin` and create the first account. A random `WUPPY_SECRET` is written to `.env`.
