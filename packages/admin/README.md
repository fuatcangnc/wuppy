# @wuppycms/admin

The admin panel of [WuppyCMS](https://wuppycms.com): a React single-page app served by the `wuppycms` Astro integration
at `/admin`. It holds the content editor, media library, menus, users, settings, themes and the visual editor.

> This package is part of [WuppyCMS](https://wuppycms.com) and is installed with `wuppycms`. You do not need to install
> it yourself.
