# @wuppycms/plugin-types

Types and the API contract for [WuppyCMS](https://wuppycms.com) plugins. Plugins run in a WebAssembly sandbox and only get
the capabilities their manifest asks for and the admin approves.

```sh
npm install -D @wuppycms/plugin-types
```

See [Plugins](https://docs.wuppycms.com/plugins/overview/) in the documentation.
