title: WuppyCMS — the file-based CMS for Astro
description: WuppyCMS adds an admin panel to your Astro site. Content stays in Markdown files, every save is a Git commit, and editors get a visual editor.
eyebrow: CMS for Astro
headline: Your Astro site, with an admin your clients can use.
lead: WuppyCMS keeps content in Markdown and MDX files in your repository. Editors work in a clean admin with a visual editor; you keep plain files, Git history and your own Astro code.
featuresTitle: Everything a site needs, nothing it does not own
features:
  - title: Content is files
    text: Markdown and MDX in your repo. Remove WuppyCMS and every page still reads.
  - title: Every save is a commit
    text: See what changed, compare versions and undo. History is never lost.
  - title: Visual editor
    text: Edit blocks and your theme's own markup on the page, per device, with live preview.
  - title: GitHub themes
    text: Install any Astro repository as a theme; its pages and content come with it.
  - title: Users and roles
    text: Admin, editor, author and viewer, with two-factor sign-in, passkeys and a security log.
  - title: Safe plugins
    text: Plugins run in a WebAssembly sandbox with only the capabilities you approve.
  - title: Media and SEO
    text: Uploads with focal points and crops, redirects, sitemaps and social previews.
  - title: Many sites, one hub
    text: Manage client sites from one place and publish to any of them.
howTitle: How it works
steps:
  - title: Create
    code: npm create wuppycms my-site
    text: A new Astro site with WuppyCMS, or add the wuppycms() integration to an existing one.
  - title: Describe
    code: wuppy.config.mjs
    text: List your collections and fields; WuppyCMS builds the forms from them.
  - title: Edit
    code: /admin
    text: Sign in, invite your team and publish. Node.js is all it needs.
